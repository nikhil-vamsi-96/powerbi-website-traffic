# 🌐 Website Traffic Analytics — Power BI

A web analytics project analyzing approximately **88K sessions** across traffic sources and devices to understand website engagement, conversion performance, and channel quality.

## 🎯 Business Problem

Marketing teams need to know which acquisition channels bring valuable visitors—not simply the most traffic.

This project uses Power BI and DAX to compare traffic volume, engagement, and session quality so marketing decisions can focus on **high-performing channels and audiences**.

## 🧰 Tools

- **Power BI** — dashboard and interactive reporting
- **DAX** — time intelligence and calculated KPIs
- **Data Analysis** — channel, device, and engagement analysis

## 📊 Dataset

- ~88,000 website sessions
- Multiple acquisition/traffic sources
- Desktop and mobile device segments
- Session and engagement metrics

## 🔍 Dashboard Analysis

- Sessions and traffic trends
- Traffic-source performance
- Device performance
- Engagement behavior
- Conversion-related KPIs
- Channel comparison
- Session Quality Score
- Time-based performance analysis

## 🧮 Session Quality Score

A custom **Session Quality Score** is used to evaluate the quality of website sessions beyond raw traffic volume.

This helps distinguish channels that generate **high-volume traffic** from channels that generate **more valuable and engaged users**.

## 💡 Business Value

The dashboard helps answer questions such as:

- Which channels generate the most traffic?
- Which channels attract higher-quality sessions?
- How does performance differ by device?
- Which traffic sources deserve more marketing attention?
- How does website performance change over time?
