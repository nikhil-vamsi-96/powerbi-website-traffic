# 🌐 Website Traffic Analytics — Power BI

An interactive **Power BI marketing analytics dashboard** analyzing approximately **88K website sessions** across traffic sources and devices to understand engagement, conversion performance, and channel quality.

## 🎯 Business Problem

Marketing teams need to understand which acquisition channels bring **valuable visitors**, not simply the highest traffic volume.

This project uses **Power BI and DAX** to compare traffic, engagement, session quality, and conversion-related KPIs so marketing decisions can focus on high-performing channels and audiences.

## 🧰 Tools & Skills

- **Power BI** — interactive dashboard and reporting
- **DAX** — calculated KPIs and time-based analysis
- **Data Modeling** — analytical dimensions and KPI reporting
- **Marketing Analytics** — acquisition, engagement, device, and channel analysis

## 📊 Dataset

- Approximately **88,000 website sessions**
- Multiple acquisition/traffic sources
- Desktop and mobile device segments
- Session and engagement metrics
- Time-based website activity

## 📌 Key KPIs & Analysis

The dashboard analyzes:

- Total sessions
- Traffic trends over time
- Traffic-source performance
- Device performance
- Engagement behavior
- Conversion-related KPIs
- Channel comparison
- Session Quality Score

## 🧮 Session Quality Score

A custom **Session Quality Score** evaluates website sessions beyond raw traffic volume.

This helps distinguish channels that generate **high-volume traffic** from channels that generate more valuable and engaged sessions.

## 💡 Business Questions

The dashboard helps answer:

- Which channels generate the most traffic?
- Which channels attract higher-quality sessions?
- How does website performance differ by device?
- Which traffic sources deserve more marketing attention?
- How does performance change over time?

## 🚀 Business Value

The analysis provides a framework for prioritizing acquisition channels based on **traffic quality and engagement**, rather than relying only on session volume.

Potential decisions include reallocating marketing attention toward stronger channels, investigating underperforming sources, and optimizing experiences for different device segments.
